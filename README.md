# Java Quest — أصلح المحطة

لعبة تعلّم أساسيات جافا للمبتدئين تماماً: ١٠ دروس، وفي كل درس ٦ مراحل تنفتح بالترتيب.

## طريقة التشغيل
افتح `index.html` في المتصفح، أو ارفع المجلد كامل على أي استضافة (Netlify، GitHub Pages).
لازم ترفع المجلد بكل ملفاته، مو `index.html` لحاله.

## ترتيب الملفات
```
index.html              الصفحة، وفيها ترتيب تحميل الملفات
css/style.css           التصميم كامل (فاتح وداكن)
js/data/lessons.js      الدروس العشرة وشرحها
js/data/questions.js    أسئلة «أصلح النظام»
js/data/activities.js   صح أو غلط، والمطابقة، والأخطاء، والبطاقات
js/data/tasks.js        مهام «اكتب الكود بنفسك»
js/config.js            الإعدادات وترتيب المراحل
js/storage.js           حفظ التقدم في جهاز اللاعب
js/utils.js             أدوات مشتركة وحساب المراحل المفتوحة
js/ai.js                ربط نوفا بالذكاء الاصطناعي
js/question.js          عرض الأسئلة
js/home.js              الشاشة الرئيسية
js/folder.js            مجلد الدرس والمراحل
js/lesson.js            شاشة الشرح وسؤال التأكد
js/training.js          مرحلة «أصلح النظام»
js/activities.js        المراحل من ٣ إلى ٦
js/notebook.js          دفتر أخطائي
js/nova.js              مزايا نوفا الإضافية
js/main.js              تشغيل اللعبة
```

## إضافة أسئلة
- سؤال تدريب جديد: أضفه في `js/data/questions.js` بنفس شكل الأسئلة الموجودة، و`c` رقم الدرس (يبدأ من 0).
- جملة صح أو غلط، أو كود للمطابقة، أو خطأ جديد: أضفه في `js/data/activities.js` داخل الدرس المطلوب.

## ملاحظة عن نوفا
مزايا نوفا (الذكاء الاصطناعي) تشتغل بس لما تنفتح اللعبة داخل Claude. برا Claude تختفي تلقائياً وباقي اللعبة تشتغل عادي.
