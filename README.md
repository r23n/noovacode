# Java Quest — أصلح المحطة

لعبة تفاعلية لتعلّم أساسيات لغة **Java** من الصفر. يتقدم اللاعب داخل محطة فضائية عبر دروس قصيرة وتحديات عملية، بحيث يتعلم المفهوم ثم يطبقه مباشرة بدل الاكتفاء بالقراءة.

## ماذا يتعلم اللاعب؟

تتكون اللعبة من 10 دروس مرتبة تدريجيًا، تبدأ بالطباعة على الشاشة وتنتهي بالدوال. يحتوي كل درس على ست مراحل تفتح بالتسلسل:

1. شرح مبسط مع مثال برمجي.
2. سؤال تأكد سريع.
3. تدريب «أصلح النظام» لفتح الدرس التالي.
4. صح أو غلط.
5. مطابقة الكود مع النتيجة.
6. اكتشاف الخطأ وبطاقات المراجعة.

وتتضمن اللعبة أيضًا دفترًا لتسجيل الأخطاء ومراجعتها، مع حفظ تقدم اللاعب تلقائيًا على جهازه.

## التشغيل

لا يحتاج المشروع إلى تثبيت حزم أو إعداد خادم محلي.

### تشغيل مباشر

افتح ملف `index.html` في المتصفح.

### نشر على استضافة

ارفع مجلد المشروع كاملًا إلى أي استضافة للملفات الثابتة، مثل:

- GitHub Pages
- Netlify
- Vercel

> يجب رفع المجلد كاملًا، لأن الصفحة تعتمد على ملفات JavaScript وCSS الموجودة في المجلدين `js` و`css`.

## نوفا والذكاء الاصطناعي

نوفا مساعدة اختيارية تظهر عند تشغيل اللعبة داخل بيئة Claude التي تدعم ميزة الذكاء الاصطناعي. تساعد اللاعب على فهم سبب الخطأ وشرح الكود بطريقة مبسطة.

إذا لم تتوفر الميزة، تختفي أدوات نوفا تلقائيًا وتستمر جميع أجزاء اللعبة الأساسية في العمل بشكل طبيعي.

## هيكل المشروع

```text
index.html              نقطة الدخول وترتيب تحميل ملفات اللعبة
css/style.css           التصميم والوضعان الفاتح والداكن
js/data/lessons.js      محتوى الدروس والأمثلة البرمجية
js/data/questions.js    أسئلة مرحلة «أصلح النظام»
js/data/activities.js   بيانات الصح والخطأ والمطابقة والأخطاء والبطاقات
js/data/tasks.js        مهام كتابة الكود
js/config.js            الإعدادات وترتيب مراحل الدرس
js/storage.js           حفظ واستعادة تقدم اللاعب محليًا
js/utils.js             الأدوات المشتركة وحساب المراحل المفتوحة
js/ai.js                الاتصال الاختياري بمزايا نوفا
js/question.js          عرض الأسئلة والتعامل مع الإجابات
js/home.js              الشاشة الرئيسية
js/folder.js            شاشة الدرس ومراحله
js/lesson.js            شاشة الشرح وسؤال التأكد
js/training.js          منطق مرحلة «أصلح النظام»
js/activities.js        منطق المراحل التفاعلية
js/notebook.js          دفتر أخطاء اللاعب
js/nova.js              واجهة مزايا نوفا
js/main.js              تهيئة اللعبة وتشغيلها
```

## إضافة محتوى جديد

### إضافة درس

أضف بيانات الدرس في `js/data/lessons.js` مع المحافظة على نفس بنية الدروس الموجودة. ترتيب الدرس داخل المصفوفة يحدد رقمه وتسلسل ظهوره.

### إضافة سؤال تدريب

أضف السؤال في `js/data/questions.js` بنفس صيغة الأسئلة الحالية. قيمة `c` هي رقم الدرس، وتبدأ من `0`.

### إضافة نشاط

أضف جمل الصح والخطأ، أو عناصر المطابقة، أو الأخطاء البرمجية، أو بطاقات المراجعة في `js/data/activities.js` داخل بيانات الدرس المطلوب.

## التقنية

- HTML
- CSS
- JavaScript بصيغة Vanilla
- تخزين التقدم عبر `localStorage`
- لا توجد عملية بناء أو اعتماد على إطار عمل

## المساهمة

لإضافة محتوى أو تحسين تجربة التعلم:

1. أنشئ فرعًا جديدًا للتغيير.
2. اختبر اللعبة بفتح `index.html` والتنقل بين الدروس والأنشطة.
3. تأكد من أن التعديلات تعمل على الشاشات الصغيرة والكبيرة.
4. أرسل Pull Request يوضح ما تغير ولماذا.
